# Снимок дашборда

Один тик дашборда (не дольше 30 секунд, `dashboardCacheTTL`) читает Медиалог один раз для всех открытых строк. Доступ, персональные данные, счётчики и PATCH берут этот снимок. Показ данных внутри этих 30 секунд сохраняется.

Если снимок показывает перенос, `waitlist.branch_id` обновляется до подсчёта страницы. Видимость всё равно решает снимок: известный филиал видят его сотрудники, администратор и менеджер; неизвестный филиал — только администратор и менеджер; пропавшая исходная запись MAX остаётся по филиалу в SQLite и только с полями SQLite. Строки регистратуры без записи в снимке не показываются.

Если чтения нет или снимок старше 30 секунд, страница показывает «Медиалог недоступен». Регистратура скрыта. Строки MAX остаются по филиалу в SQLite, без полей Медиалога. Кэш персональных данных сбрасывается по таймеру раз в срок снимка.
