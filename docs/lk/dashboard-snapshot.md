# Снимок дашборда

Окно регистратуры и обогащение страницы листа ожидания хранятся не дольше 30 секунд (`dashboardCacheTTL`).

Пока этот срок не истёк, строка, которую в Медиалоге перенесли в другой филиал, может оставаться у прежнего филиала. Следующее чтение филиалов открытых записей MAX обновляет `branch_id` и счётчики.

Ошибка чтения Медиалога не отдаёт персональные данные регистратуры из кэша старше этого срока. Такие строки на страницу не попадают. Строки MAX при этом остаются.
