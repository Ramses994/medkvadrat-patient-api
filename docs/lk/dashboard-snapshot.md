# Снимок дашборда

На процесс один снимок Медиалога. Он живёт не дольше 30 секунд (`dashboardCacheTTL`). У снимка одно поколение: каждое успешное чтение увеличивает его на 1. Вкладки, счётчики и PATCH одного запроса берут один и тот же указатель. Чтение всегда одно: окно регистратуры и детали всех незакрытых строк MAX и всех строк окна.

Кто видит строку, решает снимок, а не `waitlist.branch_id`. Известный филиал (106, 3, 496) видят его сотрудники, администратор и менеджер. Неизвестный филиал и филиал 0 — только администратор и менеджер. Пропавшая строка MAX остаётся по филиалу в SQLite и без полей Медиалога. Строка регистратуры, которой нет в чтении деталей, скрыта. Списки, `total` и `open_total` считаются в памяти после этой проверки.

`waitlist.branch_id` — только запас на случай, когда снимка нет или строка пропала. Он пишется один раз на поколение, сразу после успешного чтения, и только если это поколение всё ещё текущее. Ноль в SQLite не пишется. Ошибка записи в журнал не меняет доступ.

Если чтения нет, страница показывает «Медиалог недоступен». Регистратура скрыта. Строки MAX остаются по филиалу в SQLite, без полей Медиалога. Просроченный снимок выбрасывается по таймеру.
